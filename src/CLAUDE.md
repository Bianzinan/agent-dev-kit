## 构建与测试

```bash
# 待填写：怎么装依赖
# 待填写：怎么跑起来
# 待填写：怎么跑测试
```

把测试入口定义成 `test-product` 目标，放在 **`Makefile.product`** 里
（`cp Makefile.product.example Makefile.product`）：

```makefile
test-product: ## 运行工程层测试
	pytest        # 换成你的命令
```

根 `Makefile` 的 `test` 会先跑脚手架回归测试，再自动调用 `test-product`——**定义了才跑**，
没定义就跳过。单独一个文件是为了升级基座时不和你的目标冲突；根 `Makefile` 属于脚手架层。
